# CrossGL JSON Schema Index

This page lists every current public JSON contract emitted or consumed by
`cglc`.
Consumers should branch on each document's `schemaVersion` before reading nested
fields. Individual guide pages define compatibility policy and field details for
each contract.

## M1 v0 Package Freeze

The M1 v0 package freeze is a stability boundary for the package JSON contracts
that are currently published as `schemaVersion: 1`. Consumers should treat any
unknown `schemaVersion` as incompatible unless they deliberately opt into a
newer contract.

The frozen package boundary covers these surfaces:

- Package manifest JSON: compiler identity, module/target identity, source
  hash, and manifest artifact path map.
- Diagnostics JSON: diagnostic record shape, severity values, source-location
  span fields, optional target, and missing capability list shape. Diagnostic
  codes and capability IDs remain open-ended strings.
- Reflection JSON: module/target identity, entry-point/resource/binding
  collections, native-binary reference, and target feature records. New target
  feature identifiers may be added without changing package target semantics.
- Artifact inventory JSON: package inspect root-file and artifact status
  records, including provenance and package-relative path health. Manifest
  `nativeBinaryStatus` remains summary metadata, not a file artifact.
- Package verify JSON: success flag, package path, nullable summary,
  diagnostic counts, and verifier diagnostics.

The machine-readable schemas intentionally fail closed on document shape and
field types. Additive package fields still require updating the corresponding
schema, semantic validator, fixture coverage, and this index in the same
change. Package target mode and required-artifact facts are generated from
`tools/package_target_contracts.json` and checked by
`tools/check_package_target_contracts.py` plus
`tools/generate_package_target_contracts.py --check`; do not hand-maintain
conflicting target claims in schema docs.
