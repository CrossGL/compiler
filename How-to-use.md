# How to use this repo?

__1)__ Clone this repo to your system!  
__2)__ Add a directory of the backend you are working on!  
__3)__ 'add_subdirectory(your_dir_name' should be added in the main CMakeLists.txt!  
__4)__ Add a CMakeLists.txt in your working directory specifying your dir as a static library!  
__5)__ After successful linking, please mention your name and your working backend name in the contributors.md!  
__6)__ Lastly, feel free to asl for any help!
